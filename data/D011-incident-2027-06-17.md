# Incident Report 2027-06-17 - Gateway fallback storm

## Impact

For 74 minutes the agent gateway returned elevated latency on all routes.
Kettlebridge in-app summarisation timed out for roughly 40% of requests.

## Cause

The primary provider for the `summarise-long` route degraded.
The gateway failed over to the fallback model as designed.
The fallback has a lower rate limit, so the combined traffic from three ventures exceeded it and produced retry amplification.

## Contributing factor

Retries were configured with a fixed 1 second delay and no jitter.

## Actions

- Add exponential backoff with jitter. Owner platform team. Done 2027-06-25.
- Add a per route concurrency limit at the gateway. Owner platform team. Open.
- Add a dashboard panel for fallback rate per route. Owner platform team. Open.
