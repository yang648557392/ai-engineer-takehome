# Ticket LEGAL-4477 - Orlo DPO sign-off for photo processing

**Reporter:** Orlo engineering
**Assignee:** group DPO

## Request

Orlo requests DPO sign-off for processing user submitted plant photographs on shared platform infrastructure, as required by the current retention policy for special category adjacent data.
This is a prerequisite for the vector namespace request in PLAT-4411.

## Status

Open.
The DPO has asked Orlo for a data protection impact assessment covering background people in photographs before ruling.
Orlo has not yet submitted the assessment.
